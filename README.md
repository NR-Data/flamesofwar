# Flames of War v4 data

Army list data files for Flames of War v4.

> **Community rehost.** These files were written by the community contributors listed below and were previously published at `github.com/BSData/flamesofwar`, which is no longer online. This copy keeps them available and open to updates.
>
> They are not made, maintained or endorsed by NewRecruit. Nobody here is affiliated with or endorsed by the publisher of Flames of War v4. All game names and trademarks belong to their respective owners. You still need the official rules to play.

## Is this maintained?

It is open for updates, not archived. It is kept up by whoever contributes to it, so check the commit history to see how current it is. Last data change before the rehost: 2025-10-22.

## How to update it

- **Pull request:** fork this repository, make your changes and open a pull request.
- **Write access:** if you want to maintain this game, ask on the NewRecruit Discord: https://discord.gg/cCtqGbugwb

## File format

The files are JSON, converted on 2026-11-16 from the original BattleScribe XML (`.cat`/`.gst`). The XML versions are in the git history before that commit.
